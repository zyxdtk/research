## 一、一句话结论

**中际旭创是AI资本开支的直接收款方**——H1营收417.78亿元（+182.5%）、净利136.51亿元（+241.7%），Q2单季净利同比+228%（推算），业绩没有任何问题；问题在股价已从高点回落41.5%。**这不是基本面问题，是"涨太快"的问题**——接下来只看800G/1.6T光模块的出货能否在Q3继续翻倍，能，就是错杀；不能，46倍PE要重新算。

## 三、分析框架：终局利润怎么看中际旭创

### 3.1 利润从哪来
全球云厂AI资本开支 → 光模块是服务器与交换机之间的"必选消耗品" → 800G放量、1.6T起量。它不赌模型能不能赢，只赌**集群规模**。这与CXO"卖水人"是同一类商业模式，只是客户更集中、迭代更快。

### 3.2 为什么股价-41.5%而业绩+241%
1. 前期涨幅过大（YTD仍+32.7%），获利盘集中兑现
2. Q3 创业板 -27.8%、科创50 -30.7% 的系统性回撤
3. 市场担心AI资本开支持续性（机构开始质疑"巨额支出谁买单"，2026-09-30报道 ◐）

### 3.3 估值测算
按2026H1年化，全年净利约270-300亿元 → 9,523亿市值对应2026E PE约**32-35倍**；若Q3维持翻倍级增速，动态估值更低。**46.5倍的TTM口径是滞后的**，这也是为什么不能只看PE-TTM。

**中际旭创是三者中唯一"业绩与股价背离"的**（其余是业绩平平股价也跌）。

## 六、风险提示

1. **客户集中风险**：AI算力链客户高度集中，单一大客户订单波动影响巨大
2. **技术迭代风险**：光模块技术路线（硅光/CPO/薄膜铌酸锂）变化可能重构格局

4. **宏观与地缘**：AI资本开支的持续性正被机构质疑（◐）
