## 四、整体判断：会继续跌，反转需要宏观或数据

下跌不是业绩驱动（Q3全线兑现），是叙事与资金驱动：2027年供给释放预期（扩产潮万吨规划，见10月版）、AI capex消化、12月加息定价约85%、公募与南向双出清。技术面19只全部在高点下方50%+、无一完成筑底。

**概率口径（本报告估计）**：继续创新低或反复筑底约七成；V型反转约三成——需"联储12月不加息/降息"或"1.6T季度出货超预期＋2027年长单落地"两者之一先行。在此之前，板块内一切反弹按**减仓与交易窗口**处理，不构成趋势性抄底依据。反转顺序的观察链：联储定价变化 → 公募/南向止卖 → 旭创/新易盛停止阴跌 → 板块缩量 → 个股右侧。
