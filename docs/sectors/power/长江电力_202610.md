## 一、一句话结论

**长江电力是"在别人腰斩的时候你还赚钱"的那类资产**——H1净利+13.0%、毛利率57.9%、YTD +9.0%、距高点-3.2%，六个覆盖标的里唯一贴着高点的。但要清醒：Q2单季净利只+1.5%（推算），它赚的是**水 + 股息 + 估值稳定**的钱，不是成长的钱——**把它当底仓，不要当进攻**。

## 三、分析框架：终局利润怎么看长江电力

### 3.1 它的终局是什么
六座巨型水电站不可复制，折旧逐步到期后现金流进一步释放，模式接近**基础设施REITs**：电价市场化波动被长期协议对冲，赚的是"水免费 + 资产折旧完 + 高分红"。终局利润稳定但增速低（个位数）。

### 3.2 为什么在2026年涨
- 系统性回撤里资金逃向确定性（创业板Q3 -27.8%）
- 股息率对无风险利率的利差仍有吸引力
- **这不是成长逻辑，是避险逻辑**——避险逻辑在市场企稳后会减弱

### 5.3 三条路径观察哨

- **乐观**：来水好+分红提升 → 突破年内高点（+3%以上），赚股息+小幅估值提升
- **中性**：净利+8~10%、股息稳定 → 慢牛，年化收益≈股息+业绩（当前基准）
- **悲观**：来水转差或电价改革压缩利润 → 回吐至年初水平（约-9%）

**核心一句话**：它的持有逻辑只有一个——**股息能不能稳定在3.5%以上**，其余（增长、催化）都是次要变量。

## 六、风险提示

1. **来水风险**：水电靠天吃饭，单季净利波动大（Q1 +30.5% → Q2 +1.5%）
2. **估值与避险退潮**：市场风险偏好回升时，防御资产可能跑输
3. **电价机制风险**：市场化改革可能压缩利润空间
4. **增速天花板**：个位数增长，估值不宜按成长股给
5. **数据口径**：Q2单季为H1−Q1推算
