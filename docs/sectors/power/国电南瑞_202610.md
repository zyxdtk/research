## 一、一句话结论

**国电南瑞是电网侧唯一"收入双位数增长 + 股价距高点-27%"的错配**——H1营收+14.5%、Q2单季+18.6%（推算）说明电网投资在落地，但归母只+4.1%、YTD仅+3.0%，市场没有为它定价。**它需要的不是逻辑，是一个招标/订单催化**；催化来了是弹性，不来就是横盘。

## 三、分析框架：终局利润怎么看国电南瑞

### 3.1 买它买的是什么
电网二次设备（保护控制、调度自动化、换流阀控制系统）龙头。终局逻辑：**只要中国继续建特高压、配网继续改造、数据中心继续接入，它的订单就是确定的**——与"卖水人"同构，客户是单一强势买方（电网）。

### 3.2 利润被谁吃掉
毛利率25.3%，净利率仅11%（H1）——集采压价+研发投入。**它不像水电有定价权，靠规模和份额**。所以估值只能给20倍上下，不能给成长溢价。

### 3.3 为什么是"补涨候选"
- 基本面：收入增速14.5%（比长江电力的3.4%快得多）
- 股价：YTD +3.0%、距高点-27.1%（比长江电力的+9.0%、-3.2%差得多）
- 同类：平高电气 YTD +17.9%、距高点-18.5%（**设备股里已有先行者**）
- 结论：修复方向明确，缺一个催化

## 六、风险提示

1. **单一客户风险**：利润由集采定价，议价能力弱
2. **利润与收入背离**：H1收入+14.5%但净利仅+4.1%，若持续会压制估值
3. **订单节奏风险**：电网招标季节性强，单季波动大
4. **催化不确定**：特高压核准时点不可控，滞涨期可能很长
5. **数据口径**：Q2单季为H1−Q1推算
