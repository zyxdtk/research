# 汽车数据看板

> **定位**：行业分析报告是"观点快照"（每期新文件），本看板是"数据底座"——只放原始数据和短标注，不放分析逻辑。报告引用看板，看板按月滚动更新（新月份数据替换旧月份，历史关键数据归档在底部）。
>
> **数据源约定**：销量=各公司公告/官微（乘联会/中汽协口径注明）；股价=腾讯行情（qt.gtimg.cn）；车型榜=车主之家（零售口径，不含进口）。每个数字必须有月份和口径，找不到写"未获取"。
>
> **维护节奏**：每月1-3日更新交付量+股价；月中更新乘联会/中汽协行业数据；季度更新财报。
