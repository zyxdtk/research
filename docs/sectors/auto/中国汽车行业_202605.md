# 港股汽车板块综合分析报告

**报告日期：2026年5月31日**

---

## 一、板块概况

### 1.1 市场定位

2025年的香港交易所，正成为中国汽车产业最炙手可热的展示橱窗。从整车龙头到电池巨头，从自动驾驶新锐到智能座舱供应商，汽车产业链的各个环节正在这里集结。奇瑞结束21年上市长跑，宁德时代创下近四年H股融资新高，赛力斯刷新年度最大车企IPO纪录——这些标志性事件密集发生，勾勒出一幅资本与产业深度融合的图景。

### 1.2 板块分类

当前，港股市场上的汽车股大致可分为四大类：

**1. 传统品牌车企**
- 比亚迪（01211.HK）：新能源龙头，全球首个全面废除燃油车的传统品牌车企
- 长城汽车（02333.HK）：以生态出海构建差异化优势
- 吉利汽车（00175.HK）：多品牌战略，出海与高端化并进

**2. 造车新势力**
- 理想汽车（02015.HK）：增程式电动车代表，曾连续三年保持年度盈利
- 蔚来（NIO）：高端智能电动车，换电模式创新者
- 小鹏汽车（09868.HK）：智能化先锋，自动驾驶技术领先
- 零跑汽车：性价比路线，2025年首次实现全年盈利

**3. 新晋上市车企**
- 奇瑞汽车（9973.HK）：2025年港股上市，首份年报表现亮眼
- 赛力斯：华为智选模式，年度最大车企IPO
- 小米汽车：小米集团旗下，智能电动汽车业务首次实现经营收益转正

**4. 汽车产业链企业**
- 宁德时代：动力电池龙头
- 汽车零部件供应商
- 智能驾驶解决方案提供商

## 二、主要上市公司分析

### 2.1 比亚迪（01211.HK）—— 新能源龙头

**核心数据（2025年）：**
- 营收：8039.65亿元，同比增长3.46%
- 净利润：337.61亿元，同比下降18.82%
- 销量：460.24万辆，同比增长7.73%
- 研发投入：634亿元，远超净利润
- 市值：约1.14万亿港元
- 估值：P/B 5.84倍，2025年预估P/E 21.95倍

**竞争优势：**
1. 连续4年蝉联全球新能源销冠，首次超越特斯拉登顶全球纯电销量第一
2. 垂直整合策略，从电池、电驱系统到整车制造的全产业链布局
3. 工程师文化浓厚，在技术壁垒、成本控制、管理层禀赋三大维度建立深护城河
4. 全球化布局加速，出海成为重要增长引擎

**风险提示：**
- 净利润同比下降18.82%，研发投入巨大影响短期盈利
- 估值透支风险（PE 34倍）
- 价格战压力持续

### 2.2 理想汽车（02015.HK）—— 增程式先锋

**核心数据（2025年）：**
- 营收：1123亿元，同比减少22.3%
- 毛利率：18.7%（2024年为20.5%）
- 经营亏损：5.21亿元
- 研发费用：113亿元
- 前11个月交付量：约53.61万辆，同比增长113.42%

**经营状况：**
- 昔日"交付王"明显失速，整体交付量已被小鹏超越
- 第3季纯电车型i6、i8订单号称突破10万，但转型面临挑战
- 重整销售渠道，应对市场竞争加剧

**风险提示：**
- 营收、净利润和销量三项指标全部同比下降
- 从连续三年盈利转为经营亏损
- 增程式技术路线面临纯电竞争压力

### 2.3 零跑汽车 —— 性价比之王

**核心数据（2025年）：**
- 交付量：近60万辆，领跑造车新势力
- 首次实现全年盈利，成为造车新势力中的亮点

**竞争优势：**
- 性价比定位精准，产品力突出
- 成本控制能力强
- 海外合作模式（Stellantis）打开新增长空间

### 2.4 蔚来与小鹏 —— 智能化先锋

**蔚来（NIO）：**
- 2025年第四季度营收346.5亿元，领先其他新势力
- 实现史上单季盈利
- 卖一辆车仍要亏4.58万元，盈利能力待提升
- 换电模式构建差异化优势

**小鹏汽车（09868.HK）：**
- 2025年全年毛利率最优
- 实现史上单季盈利
- Q1业绩超预期，新车上市有望继续提升销量
- 自动驾驶技术领先

### 2.5 奇瑞汽车（9973.HK）—— 新晋上市

**核心数据（2025年）：**
- 营收：3002.9亿元，同比增长11.3%
- 净利润：195.1亿元，同比增长36.1%
- 港股上市后首份完整年报表现亮眼

**竞争优势：**
- 新能源转型成效显著
- 海外市场表现强劲
- 出口业务成为核心支撑

### 2.6 吉利汽车（00175.HK）—— 多品牌战略

**核心数据（2025年Q1）：**
- 营收：724.95亿元，同比增长25%
- 归母净利润：56.72亿元，同比增长264%
- 极氪私有化开始推进

**竞争优势：**
- 多品牌矩阵（吉利、领克、极氪、沃尔沃等）
- 出海战略成效显著
- 高端化转型成功

## 三、行业趋势分析

### 3.1 新能源渗透率持续提升

**关键数据：**
- 预计2025年中国新能源渗透率达55%
- 混动技术加速新能源渗透
- 智能驾驶加快渗透至20万元以下市场

**趋势特点：**
1. 从政策驱动转向市场驱动
2. 混动车型成为过渡期重要选择
3. 智能化成为新的竞争焦点

### 3.2 出海成为核心增长引擎

**市场表现：**
- 2025年中国汽车出口延续高增长态势
- 月度出口量整体呈逐月攀升趋势
- 比亚迪以105.4万辆出口量跃居全球第二
- 中国自主新能源品牌海外市场份额达15.3%（较2021年的1.8%显著提升）

**出海优势：**
1. 完整的新能源汽车产业链
2. 技术领先优势（电池、智能驾驶）
3. 成本竞争力强
4. 东南亚、印度、拉美等新兴市场快速增长

**政策支持：**
- "深港汽车快通计划"启动，新能源汽车抵港后可快速上牌
- 企业仓储成本降低65%，香港市民购车周期缩短70%
- 比亚迪等企业预计每年减少运营支出超2000万

### 3.3 智能化加速渗透

**技术趋势：**
1. 高阶智驾渗透率快速上升
2. "智驾平权"正在袭来，智能驾驶下沉至20万元以下市场
3. 2025年开年迎来两场技术风暴（DeepSeek等）
4. 机器人产业化提速，成为新增长空间

**竞争格局：**
- 小鹏汽车在自动驾驶技术方面领先
- 华为智选模式（赛力斯、奇瑞等）快速崛起
- "华米零"格局正在形成（华为、小米、零跑）

### 3.4 资本市场格局重塑

**港股成为"车圈"风向标：**
- 2025年港股汽车板块脱颖而出
- 从传统车到"华米零"，资本故事重写
- 港股通汽车指数估值相对合理

**估值水平：**
- 港股通汽车指数的PE和PB均低于同类指数
- 对于成长性较强的汽车指数来说处于较为合理的区间
- 比亚迪：P/B 5.84倍，2025年预估P/E 21.95倍，市值1.14万亿港元

## 四、机遇与挑战

### 4.1 发展机遇

**1. 政策持续支持**
- 2026年新能源汽车购置税由"全额免征"转为"减半征收"
- 主流车企推出"购置税兜底"与金融补贴对冲政策影响
- 预计2025年底至2026年初将形成一波新的订单与交付

**2. 出海高景气**
- 中国汽车出口延续高增长态势
- 海外市场份额持续提升
- 新兴市场（东南亚、印度、拉美）快速增长

**3. 智能化转型**
- 高阶智驾渗透率上升
- 机器人产业化提速
- 新技术应用场景拓展

**4. 估值修复空间**
- 此前的悲观预期已得到较好程度的定价
- 后续有望好转
- 港股汽车板块估值相对合理

### 4.2 面临挑战

**1. 价格战加剧**
- 传统车企和新势力车企产能集中释放
- 行业利润率承压
- "增收不增利"现象普遍

**2. 政策退坡压力**
- 2026年新能源汽车购置税优惠力度减弱
- 补贴政策逐步退出
- 市场化竞争加剧

**3. 供应链波动**
- 锂、钴、镍等关键资源价格波动
- 地缘政治冲突影响
- 电池成本不确定性

**4. 竞争格局激烈**
- 传统车企加速转型
- 新势力车企分化加剧
- 科技公司跨界造车（华为、小米）

**5. 基础设施瓶颈**
- 充电桩建设仍需加速
- 换电站布局不均衡
- 智能网联基础设施待完善

## 五、投资建议

### 5.1 板块配置策略

**整体观点：港股汽车板块具备配置价值**

**理由：**
1. 出口高景气带来坚实基本面
2. 悲观预期已得到较好定价
3. 智能化转型加速，新增长空间打开
4. 估值相对合理，修复空间较大

### 5.2 标的选择建议

**龙头配置：**
- **比亚迪（01211.HK）**：新能源龙头，规模优势明显，全球化布局领先，适合长期配置
- **吉利汽车（00175.HK）**：多品牌战略成功，出海成效显著，估值相对合理

**成长性配置：**
- **零跑汽车**：首次全年盈利，性价比路线清晰，海外合作打开新空间
- **小鹏汽车（09868.HK）**：智能化领先，毛利率最优，Q1业绩超预期

**主题性配置：**
- **奇瑞汽车（9973.HK）**：新晋上市，业绩亮眼，新能源转型成功
- **赛力斯**：华为智选模式，智能化主题

### 5.3 风险提示

1. **价格战风险**：行业竞争加剧，利润率承压
2. **政策风险**：补贴退坡，政策支持力度减弱
3. **技术路线风险**：技术迭代快速，投资决策难度大
4. **估值风险**：部分标的估值较高，透支未来增长
5. **地缘政治风险**：出海面临贸易壁垒和政策不确定性

### 5.4 自动驾驶与Robotaxi：终局思维下的格局重构（2026年5月更新）

#### 5.4.1 百度萝卜快跑模式受挫

**2026年3月武汉重大故障事件：**
- 3月31日晚间，武汉市多个主干道近百辆萝卜快跑车辆突然停驶于路中央
- 造成交通拥堵并引发多起剐蹭事故，有乘客被困高架近两小时
- 截至2026年5月18日，仍处于全域暂停运营状态（已40多天）
- 百度至今未做出正式回应，暴露严重的系统可靠性问题

**"科技平台+代工"模式的根本缺陷：**
- 后装改装模式成本高、一致性差
- 无法从设计阶段融入整车架构
- 仅实现"单位经济模型"层面的平衡，远未达到整体盈利
- 依赖补贴（"10公里3.9元"低价服务），实际价格高于滴滴快车

#### 5.4.2 整车制造商主导Robotaxi的新时代

**小鹏Robotaxi重大突破（2026年5月18日）：**
- 中国首台全栈自研Robotaxi量产车在广州正式下线
- 这是中国首次由整车厂以全栈自研方式完成Robotaxi量产
- 搭载4颗图灵AI芯片，车端算力高达3000 TOPS（全球最高）

**整车厂模式的差异化优势：**
| 维度 | 整车厂模式（小鹏） | 科技公司模式（百度） |
|------|-------------------|-------------------|
| **前装量产** | 从设计阶段融入，预留预装孔位 | 后装改装，成本高、一致性差 |
| **制造成本** | 大幅降低制造成本 | 改装成本偏高 |
| **系统可靠性** | 高 | 存在安全隐患 |
| **数据闭环** | 依托量产车数据积累 | 依赖专门测试车队 |

**主要玩家战略进度：**
- **小鹏**：2026年下半年启动载客运营，2027年成本低于人类司机
- **特斯拉**：Cybercab 2026年4月规模化生产，美国区域无监管运营
- **比亚迪**：299万+量产车保有量，数据规模优势明显
- **滴滴**：虎鲸平台2000 TOPS算力，2025年Q4启动广州北京全无人载客

#### 5.4.3 终局思维投资框架（2035年视角）

**终局格局猜想：**
- **整车制造环节**：中国市场剩下5-8家主要玩家，比亚迪、特斯拉、华为系领跑（合计50%+）
- **Robotaxi环节**：整车制造商主导（小鹏、特斯拉），出行平台转型运营方（滴滴）
- **科技公司**：可能被迫转型为技术供应商而非运营商

**终局思维配置策略：**

| 梯队 | 企业 | 终局确定性 | 配置比例 | 核心逻辑 |
|------|------|-----------|---------|---------|
| **第一梯队** | 比亚迪 | 极高 | 30-40% | 垂直整合+数据规模+全球化 |
| | 特斯拉 | 高 | 20-25% | FSD数据闭环+Cybercab领先 |
| **第二梯队** | 小鹏 | 中高 | 15-20% | Robotaxi前装量产+智能化 |
| | 吉利 | 高 | 10-15% | 多品牌+出海 |
| **第三梯队** | 滴滴 | 中 | 5-10% | 可能成为Robotaxi运营平台 |
| **需谨慎** | 理想 | 中低 | 0-5% | 增程式技术路线风险 |
| | 百度 | 低 | 0% | 萝卜快跑模式存在根本缺陷 |

**终局思维vs传统估值思维：**
- 传统估值：看PE/PB是否便宜
- 终局思维：看谁能活到2035年，以及终局的市场份额和利润
- 现在的"便宜"可能意味着终局存活确定性低，现在的"贵"可能意味着终局市值空间巨大

### 5.5 投资时点建议

**短期（2025年下半年-2026年）：**
- 关注政策托底效应（购置税优惠变化前的抢装行情）
- 关注小鹏Robotaxi载客运营进展
- 关注出海业绩兑现

**中期（2026-2028年）：**
- 关注价格战缓和后的盈利修复
- 关注智能驾驶渗透率提升
- 关注Robotaxi成本何时低于人类司机

**长期（2027年及以后）：**
- 关注行业格局出清后的龙头溢价
- 关注Robotaxi规模化后的盈利模型
- 关注全球化布局成功的企业

## 六、总结

港股汽车板块正处于从传统汽车向智能新能源汽车转型的关键时期。板块整体呈现出以下特点：

**1. 分化加剧**：龙头企业（如比亚迪）规模优势明显，新势力车企分化加速，部分企业实现盈利突破，部分企业仍面临挑战。

**2. 智能化提速**：智能驾驶、智能座舱等技术快速渗透，成为新的竞争焦点和估值支撑。

**3. 出海加速**：海外市场成为重要增长引擎，中国新能源汽车全球竞争力持续提升。

**4. Robotaxi格局重构**：2026年3月武汉事件暴露科技公司模式缺陷，5月小鹏Robotaxi量产下线标志着整车制造商主导的新时代开启。

**5. 终局思维崛起**：投资逻辑从短期业绩转向"谁能活到2035年"，整车制造商在Robotaxi时代更具优势。

**6. 政策托底**：政策支持力度虽有所减弱，但仍为行业发展提供保障。

**投资策略（终局思维框架）：** 建议以"谁能活到2035年"为核心判断，重点配置具备规模化制造、智能化研发、成本控制、全球化布局四大核心能力的企业：

- **第一梯队（40-50%）：比亚迪+特斯拉**：终局确定性最高，垂直整合+数据规模+全球化
- **第二梯队（25-30%）：小鹏+吉利**：Robotaxi前装量产+多品牌出海
- **第三梯队（10-15%）：滴滴等观察仓**：Robotaxi运营平台价值待验证
- **需谨慎（0-5%）：理想、百度**：终局存活确定性低

短期关注政策托底效应和小鹏Robotaxi运营进展，中期关注盈利修复和Robotaxi成本低于人类司机的时间点，长期关注行业格局出清后的龙头溢价。
