## 一、公司基本情况

**频准激光（688826.SH）** 成立于2017年，由曾在中国科学院上海光机所工作的"科学家型"创业者张磊创办。公司专注于**精准激光器**的研发、生产与销售，产品覆盖**177-5000nm全波段**，能够精准调控波长、线宽、噪声、功率、脉冲等参数。

公司核心技术指标已**优于德国Toptica、美国Spectra-Physics等国际巨头**，产品远销哈佛大学、麻省理工学院、苏黎世联邦理工学院等全球顶尖科研机构。

### 核心市场地位

| 领域 | 市场地位 |
|------|---------|
| 量子科技激光器（国内） | **市占率16.85%，国产品牌第一** |
| 量子科技激光器（全球） | 市占率**9.21%** |
| 半导体领域 | 2024年国内收入0.75亿元，占国内市场**1.98%** |

公司产品已服务于国盾量子、华翊量子、国仪量子等量子科技公司，以及中安半导体、昂坤视觉等半导体设备厂商。近期**Nature在线发表的"九章四号"量子计算原型机**中，频准激光自研的1550nm低噪声激光放大器为量子光源系统提供了关键支撑。

## 五、核心优势与风险

### 优势

1. **稀缺性极强**：A股"精准激光器第一股"，量子+半导体双赛道国产替代稀缺标的
2. **财务质地优异**：69%毛利率、39%ROE、高增长，在科创板新股中属于第一梯队
3. **估值折价明显**：49倍发行PE vs 行业68倍 vs 可比公司190倍
4. **技术壁垒深厚**：88项发明专利，产品性能超越国际巨头
5. **战略投资者背书**：京东方、佰维存储、中微半导体、先导智能等产业资本参与战略配售

### 风险

1. **中签门槛极高**：中一签需缴款9.34万元，绝对金额大，若破发亏损绝对值较高
2. **市场空间相对有限**：全球量子信息激光器2024年仅3.03亿美元，预计2030年达7.49亿美元
3. **发行量极少**：仅1000万股，网上仅240万股，中签率预计极低
4. **科创板波动大**：高发行价新股上市后波动可能较大

频准激光基本面扎实、稀缺性突出、估值相较行业和可比公司**明显折价**，财务质地在科创板新股中属于**顶尖水平**。网下认购倍数高达4250倍，机构认可度极高。**首日破发概率较低**，市场预期溢价空间较大。

## 七、卖出策略（首日分批止盈）

**核心策略：首日卖出。** 根据历史数据，对打新投资者而言，上市首日卖出是短期内的最佳策略。

频准激光是**2026年以来发行价最高的新股**，"高价股，不管涨幅，首日卖出是最佳策略"。其基本面扎实（69%毛利率、39%ROE）、估值折价明显（49倍PE vs 行业68倍），机构认可度极高。**首日破发概率较小，溢价预期较高**。

### 具体操作建议

| 时间节点 | 操作 |
|---------|------|
| **集合竞价（9:15-9:25）** | 可预埋部分卖出委托，避免盘中情绪化决策 |
| **开盘初期（9:30-10:00）** | 多数新股首日会迎来**全天高点窗口**，建议在此时间段**分批卖出大半仓位** |
| **盘中观察** | 若首日**换手率达到45%-50%且冲高乏力**，兑现大部分仓位；若开盘涨幅超80%-100%，建议首日直接卖出或分批止盈 |
| **剩余仓位** | 可设**回落止盈**，从当日最高点回撤5%-8%时自动清仓 |

### 关键提醒

**中一签缴款9.34万元**，绝对金额大。若首日破发，亏损绝对值也会显著放大。切勿因"中签不易"而盲目长期持有——**新股首日往往是情绪高点**，长期持有反而容易利润回吐甚至破发。

## 八、打新卖出通用纪律

> 本节为新股打新卖出的通用方法论，适用于频准激光、绿控传动等新股。针对打新后的卖出时机，核心策略只有一个：**首日卖出**。

| 原则 | 说明 |
|------|------|
| **首日卖出是主流** | 绝大多数新股"上市即巅峰"，首日往往是阶段高点 |
| **分批止盈，不追求最高点** | 没人能精准卖在最高价，分批卖出可平滑波动 |
| **设回落止损** | 剩余仓位可设从高点回撤5%-8%自动卖出 |
| **破发不补仓** | 若开盘破发且无反弹迹象，及时止损，不要硬扛 |
| **提前制定计划** | 集合竞价阶段可预埋委托，避免盘中情绪化决策 |

**标的差异化执行：**
- **频准激光（高价股）**：首日分批止盈，集合竞价可预埋，开盘初期冲高兑现大半仓位，剩余设回落止盈
- **绿控传动（基本面"三高"）**：首日果断卖出，不恋战，不赌连板，财务问题可能在上市后逐步暴露
