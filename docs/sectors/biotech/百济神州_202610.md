## 一、一句话结论

**百济是创新药终局里"自建全球化体系"这条路的唯一已验证样本**：泽布替尼全球销售达约40亿美元级、海外收入占比>90%，H1净利+627%说明重资产模式已经开始产生复利——它的风险不在基本面，而在**95倍PE(TTM)对增速的容错极低**。

## 三、分析框架：终局利润怎么看百济

### 3.1 B池（全球自营销售）的复利模型
- **泽布替尼**（BTK抑制剂）：全球年销售额已达约40亿美元级（2025年报道口径 ◐），海外收入占比>90%，全球75+市场获批
- 湘财证券：全球份额登顶、进入**欧洲接力放量期**；实体瘤五大项目概念验证兑现、注册研究密集启动；**全年指引两度上调**（2026-10-01报道 ◐）
- 终局逻辑：一旦自营体系建成，每多一个适应症/地区的边际成本极低 → 这是BD授权型（恒瑞/荣昌）拿不到的**持续分成**

### 3.2 与授权型路径的利润对比
| | BD授权型（恒瑞式） | 自营型（百济式） |
|---|---|---|
| 现金流 | 一次性首付款+里程碑 | 持续销售收入 |
| 毛利 | 首付款近纯利，但规模受限 | 89.45%毛利率 + 规模效应 |
| 风险 | 里程碑不兑现 | 销售团队成本、定价压力 |
| 终局上限 | 单点最优 | **全球利润池最大** |

### 3.3 估值：为什么95倍还有人买
按2026H1年化（约65亿元净利），当前2,781亿元市值对应2026E PE约43倍；若全年净利达70-80亿元，则约35-40倍——**增速换算后并不极端**，市场分歧在于：净利能否在2027年维持50%+增长。A/H价差（A 264.41元 vs H 211.80港元≈195元）说明A股溢价约35%，H股性价比更高。

### 5.3 三条路径观察哨

- **乐观**：Q3增速≥25% + 欧洲放量超预期 → 挑战年内高点229港元（+8%），A股看313.31元前高（+18%）
- **中性**：增速20-25%、净利符合预期 → 高位震荡，H股195-229港元区间
- **悲观**：Q3增速<15% 或 BTK竞争恶化 → 95倍PE杀估值，H股看155.4年内低点（-27%）

**核心一句话**：百济已经不需要证明"能不能赚钱"，只需要证明"还能不能更快地赚钱"——**Q3增速和欧洲放量数据是唯二指标**。
