**恒瑞是"国内收入失速 + 海外授权补位"的典型样本**：H1收入-1.9%让它YTD跑输板块20个点，但9/29一笔26亿美元的GLP-1出海大单证明它的资产仍值钱——**当前股价定价的是国内悲观，未定价的是出海弹性**，三季报是否转正决定这是低估还是价值陷阱。

## 三、分析框架：终局利润怎么看恒瑞

### 3.1 国内池（C池）：收入失速的真实原因
国内创新药竞争加剧 + 医保降价 + 高基数。恒瑞毛利率86%仍在，说明不是价格战失守，而是**放量节奏与新品接续的错配**。国内池终局是"稳增长+高分红现金流"，不再是利润弹性来源。

### 3.2 海外池（A池）：HRS-1596 是标志性一单
- 2026-09-29公告：将自研**GLP-1/GIP双受体激动剂 HRS-1596** 有偿许可给**诺和诺德**，后者获得大中华区以外全球独家开发、生产和商业化权利
- 潜在总额最高**26亿美元**（约174亿元），含首付款**3亿美元**（约20.4亿元）+ 销售提成
- 产品：已具备开展I期临床条件，每周一次口服，用于肥胖症、2型糖尿病及代谢性疾病
- 财务含义：**首付款3亿美元≈恒瑞全年净利的40%量级**，且是接近纯利的授权收入

### 3.3 逻辑冲突与解答
- 冲突：H1利润没增长，为什么还给40倍PE？——因为市场给的是**BD管线价值**而非国内当期利润
- 解答：若只算国内业务，恒瑞是30倍的稳态药企；26亿美元大单说明它的GLP-1资产在全球有定价权。**估值的分歧点在"出海收入能不能常态化"**

- **乐观**：Q3收入转正 + Q4再有BD大单 → 修复至年内高点64.32元（+36%）
- **中性**：收入零增长、BD偶发 → 区间震荡42.67-59.37元（当前价的上下约-10%/+26%）
- **悲观**：Q3继续-10%以上 + 市场调整 → 跌破年内低点42.67元（-10%）

**核心一句话**：恒瑞现在的价格只反映了国内失速，**Q3单季收入是否转正是唯一的分水岭**，在此之前任何加仓都是对赌。

## 六、风险提示

1. **收入失速延续**：Q2单季-15%若延续至Q3，全年营收将负增长，40倍PE缺乏支撑
2. **BD收入非经常性**：首付款一次性，里程碑与销售分成不保证兑现
3. **竞争与降价**：国内创新药同靶点竞争加剧、医保续约降价
4. **市场Beta**：恒指YTD-4.0%，10/2港股医药大跌，高估值个股回撤放大
