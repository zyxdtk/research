## 四、核心矛盾（沿用10月框架，10月后的状态更新）

1. **国内池（C池）**：Q2单季-14.5%的失速已被Q3的+20.6%证伪为"季度性错配"而非趋势——国内企稳信号出现，但仍需Q4国谈与商保目录放量确认
2. **海外池（A池）**：HRS-1596首付3亿美元已入预期，Q3单季净利+88.9%（推算）说明授权收入确在增厚利润；后续看诺和诺德I期推进与新BD
3. **估值**：40倍PE对应的不再是"国内负增长"，而是"收入转正+出海弹性"——分歧从"会不会增长"移到"增长能不能持续到2027"
4. **逆市上涨的代价**：10月全板块杀估值时恒瑞+2.7%，短期有补跌Beta风险，回踩买优于追高
