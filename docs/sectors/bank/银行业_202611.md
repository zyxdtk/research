## 二、价格结构（公开行情，2026-10-30收盘）

10月是全市场被创业板拖着杀估值的月份，银行是少数**月线收阳且收在月内最高**的板块——招行、兴业10/30收盘价即全月最高价，月末最后五个交易日连续上攻（兴业10/26收18.68→10/30收19.65五连阳）。

- **招商银行 600036**：全月 41.0（10/8）→ 43.55（10/30收=月高）。41.0-41.5 两次探底承接（10/8低41.0、10/22-23低41.42-41.45），42.5-43.0 为10月下旬突破平台，43.55 为阶段新高（无上方套牢参照）。结构：**新高突破初期，回踩确认带42.0-42.6**。
- **兴业银行 601166**：全月 17.97（10/8）→ 19.65（10/30收=月高）。18.0-18.4 为上半月箱体，**10/27放量突破箱体上沿（开18.54收19.10）**，此后三日连创新高。结构：**突破后未回踩，18.6-19.0 为第一回补/回踩区**。
- **农业银行 601288**：月末（10/26-30）自7.17升至7.48，10/29高7.57，10/30收7.48微幅回落——大行中涨幅最大（+9.4%），月末已现高位滞涨苗头。
- **工商银行 601398**：同节奏，10/29高8.78 → 10/30收8.75。
- 整体：全板块月末加速上冲、收于高位，**短期技术面超买，11月第一周回踩属于健康范畴而非趋势破坏**。

## 三、核心判断

### 3.1 10月银行为什么逆势上涨（事实与推断分层）

**已核实的事实**：①银行主要个股10月收涨4.5%-9.4%，与创业板-23.1%反向；②招行/兴业收在全月最高；③LPR连续未动；④全球主要央行（美欧韩已加、日将加）同步紧缩。

**逻辑推断（标注为推断，非已核实归因）**：
1. **息差预期企稳**：全球加息+国内LPR按兵不动，意味着资产端定价不再下调、而负债端存款利率随市场利率被动跟随的窗口存在——净息差最坏时点可能已过（LPR未动是关键证据，方向性确认需Q3息差数据，未获取）
2. **杀估值环境的红利避险**：创业板单月-23.1%，存量资金从"成长确定性"逃向"分红确定性"，银行是A股红利资产市值最大的容器
3. **破净修复交易**：池内PB 0.49-0.93，全部破净或接近净资产，在利率上行、风险偏好收缩期，低PB本身就是防御溢价
4. **汇率稳态**：USD/CNH 6.65且在离岸几乎无价差，人民币资产中最依赖利差稳定的银行未被汇率担忧抛售

### 3.2 与全球加息周期的关系（核心框架）

当前是一个罕见的组合：**全球在加息、中国LPR在原地**。对银行的含义分两层：

- **国际维度**：美欧日韩加息抬高全球无风险利率，权益市场整体被杀估值（10月全球普跌），资金被迫寻找"利率上行本身受益或免疫"的资产——银行的息差逻辑恰好是加息周期的受益方，这解释了为什么全球同步紧缩中国银行股反而走强。
- **国内维度**：LPR 1Y 3.0%/5Y 3.5%连续未动，说明央行在"稳汇率"（中美利差已被动收窄）与"宽信用"之间选择等待。**对银行是双刃**：短期息差无新压力（未再降息）；但若2027年为稳增长重启降息，息差逻辑立即反转。这是本报告第五章"2027H1失效风险"的国内通道。

一句话：**10月银行的上涨，买的是"全球加息+中国不降息"这个组合下的息差企稳预期 + 杀估值环境的红利稀缺性。它对利率环境的依赖度极高——环境反转，逻辑即失效。**

## 五、风险

1. **红利失效的2027H1拐点（本报告最大风险，方向性）**：沿用趋势推演_202611第7条——红利是利率高位的"持有品"、不是拐点的"进攻品"。若2027H1美联储转向讨论开启、国内利率环境反转，资金将从"确定性股息"流向"成长弹性"，银行大概率跑输（2021-2022经验的反向）。**触发信号：12月FOMC出现暂停票/点阵图下移，或国内重启降息。**
2. **国内降息风险**：LPR连续未动是"等待"而非"转向"；若2027年为稳增长降息，净息差企稳预期立即反转，本轮上涨的宏观根基动摇
3. **短期超买回踩**：招行/兴业月末连阳收最高价，11月第一周技术性回踩概率高——严格按3.4档位分批，不追月末冲高价
4. **息差证据缺口**：Q3净息差、资产质量（地产/城投敞口）数据未获取，3.2的"息差最坏时点已过"目前是推断不是事实，Q3数据若证伪需下修
5. **股息率缺口**：红利性价比核心指标（股息率-10Y国债收益率）因股息率未获取**无法测算**，年报分红方案披露前，"银行作为红利资产还剩多少吸引力"无法定量回答
6. **12月FOMC超预期**：若加息至4.25%以上或暗示2027继续紧，全球风险资产二次探底，银行相对抗跌但难单独走强
7. **涨幅兑现风险**：农行10月+9.4%为池内最大，大行防御盘若在年末获利了结，可能带动板块回踩
