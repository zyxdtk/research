## 一、终局：工业超级周期里，上游最先涨价、最后跌

### 1.1 一句话结论

**资源股现在是A股港股唯一"业绩翻倍级 + 个位数到十几倍PE + 股价负收益"的组合**——紫金H1净利+68.2%但YTD -11.5%，宏桥H1净利+39.2%但YTD -31.7%，洛钼+86.3%但-14.0%；而真正涨的是煤炭油气（兖矿+53.9%、神华+21.1%、中海油+18.7%）。**资金买的是"确定性分红"，还没买"成长性资源"，这个错配就是机会本身。**

### 1.3 终局格局猜想（2030年）

- **铜**：电网改造+AI数据中心+电动车的"总需求载体"，供给端矿品位下滑、资本开支不足 → 中长期最硬的工业金属
- **铝**：电力成本决定利润（电解铝是"隐形电力股"），具备低成本水电/自备电的玩家吃掉行业利润
- **煤**：从成长回归股息资产，价格中枢抬升但弹性有限，"高股息+供给侧约束"
- **油**：地缘溢价反复，长期被新能源侵蚀，属于**事件驱动型**而非配置型
- **金**：央行购金长期逻辑在，但股价已透支过一轮（山东黄金YTD -29.0%、距高点-54.7%）

## 二、胜出者画像

1. **低成本**：铜矿看品位与采矿成本，铝看电力成本（宏桥PE 8.3 + 31.5%毛利率就是成本优势的体现）
2. **产量还在扩张**：紫金、洛钼都是"量增"驱动，不纯赌价格
3. **资产负债表干净**：周期底部熬过一轮，自由现金流可以分红
4. **一体化/出海**：海外矿山运营能力决定能不能把资源变成利润

### 5.3 三条路径观察哨

- **乐观**：铜铝价格上行 + 三季报延续高增 → 错配修复，紫金/洛钼/宏桥补涨20%+
- **中性**：价格震荡、业绩兑现但股价不涨 → 维持低配，赚业绩不赚估值（当前基准）
- **悲观**：全球需求走弱 + 地缘缓和 → 油气煤炭回吐，资源全面跑输

**核心一句话**：资源股接下来只看一件事——**三季报能不能证明"业绩+68%不是一次性"**，能证明就修复，不能就继续横着。
