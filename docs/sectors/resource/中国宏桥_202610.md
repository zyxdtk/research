## 一、一句话结论

**中国宏桥是"隐形电力股"——电解铝的胜负手是电力成本，而它有低成本电力**：H1净利172.10亿元（+39.2%）、毛利率从25.6%抬到31.5%，PE却只有8.3倍，股价YTD -31.7%。**8倍PE买39%的利润增长，这是五个方向里最便宜的一笔**；风险只有一个——铝价与电价的剪刀差会不会收窄。

## 三、分析框架：终局利润怎么看宏桥

### 3.1 铝 = 电力的另一种表达
电解铝成本中电力占比极高，谁有便宜电谁就吃掉行业利润。这也把它和方向3（电力）绑定：**电价上行利好自备/低成本电力的铝厂，利差扩大的正是它的毛利率**。

### 3.2 终局格局
- 电解铝产能天花板（国内4,500万吨红线）→ 供给刚性
- 需求端：电网、汽车轻量化、光伏边框、AI服务器散热
- 利润向拥有能源一体化的头部集中，小厂被成本挤出

### 3.3 为什么股价-31.7%
1. 港股整体弱势（恒指YTD -4.0%，10/2再跌-2.8%）
2. 铝价与宏观需求预期走弱
3. 前期涨幅过大（距高点-45.1%说明曾被炒得很高）
4. 港股流动性折价

### 5.3 三条路径观察哨

- **乐观**：铝价上行+毛利率维持30% → 估值修复到10-12倍，对应+20%~+40%
- **中性**：业绩兑现但港股不涨 → 8倍PE横盘，赚股息与业绩（当前基准）
- **悲观**：铝价回落或电价上行 → 量利双杀，看-25%

**核心一句话**：宏桥只看一个指标——**吨铝利润（毛利率）能不能守住30%**，守住就是低估守不住就是价值陷阱。
