## 三、核心判断（沿用"错配"框架）

### 3.1 10月资金行为解读

- **金银同步大跌 + 油价守113 + 南向净卖出264亿 + 12月加息定价85%** 是同一张图：资金从"避险资产/成长性资源"回流**短端美元现金与确定性股息**
- 白银跌得比黄金狠 → 撤的是投机性多头，不是央行购金逻辑本身；黄金3,884仍是历史高位区
- 结果：**买"分红确定性"（油气煤）＋卖"价格弹性"（铜铝金）**，正是10月报告预判的路径——只不过10月把后者打得更狠

### 3.2 错配是否修复：**旧方向修复完成，新方向错配反而加深**

- **已修复（兑现）**：油气煤炭——中石油10月+23.5%、神华+11.0%、中海油+10.3%，"业绩+低PE+股价负收益"的入场理由在这一支上已经用掉了，赔率下降（详见石油石化专题：A股追高赔率差）
- **未修复且加深**：铜铝金——紫金H1净利+68%但10月再跌7.4%，洛钼+86%但10月跌19.1%，宏桥+39%但再跌6.1%；山东黄金在金价高位单日-3.65%下继续杀
- **判定**：错配没消失，**是被10月的利率与商品冲击推迟了**。修复的触发条件没变——铜价/金价企稳 + 三季报证明高增不是一次性（紫金、洛钼Q3单季仍是验证点）；当前多了一个新约束：**12月加息85%定价落地前，贵金属与高弹性资源难有像样反弹**

## 五、风险

1. **错配继续不修复**：若12月加息落地、铜金价格不企稳，"业绩+68%但股价跌"可能演变为"业绩下修"——错配的另一半（业绩）被证伪
2. **油气煤炭回吐**：这一支10月已兑现（中石油+23.5%、神华+11.0%），地缘缓和或油价跌破111将双杀股息逻辑与情绪
3. **贵金属二次探底**：黄金3,884单日-3.65%、白银-6.23%，若跌破3,800/46，黄金股（山东黄金-14.6%）继续寻底
4. **宏观与资金**：12月加息定价约85%、美10Y 4.94%、南向连续8日净卖出约-264亿港元——高利率环境对资源股估值与港股流动性双重压制
5. **数据口径**：10月涨跌为9/30→10/30收盘推算；H股PE为年化粗算；宏观数据为已核实口径（◐标注）；OPEC/FOMC具体日期未核实
