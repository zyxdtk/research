**紫金是"业绩翻倍、股价下跌、估值十几倍"的标准错配样本**——H1净利391.70亿元（+68.2%），Q2单季仍+45.5%（推算），PE只有11.7倍，而YTD是-11.5%。**市场担心的不是它赚不到钱，而是铜价的持续性和7,900亿市值的天花板**；三季报若延续+40%以上，这是五个方向里赔率最清楚的一笔。

## 三、分析框架：终局利润怎么看紫金

### 3.1 终局逻辑：铜是AI时代的"总需求载体"
电网改造、数据中心、电动车、机器人——每一项都要铜。供给端矿品位下滑、新增资本开支不足，中长期价格中枢上移。金业务提供对冲。**紫金的护城河是低成本开采 + 海外矿山运营能力**，不是资源本身。

### 3.2 为什么业绩+68%而股价-11.5%
1. 2025年基数已经很高，市场担心增速自然回落（Q2 +45.5% vs Q1 +97.5% 已在回落）
2. 铜价高位的宏观敏感性：全球需求一旦走弱，价格先跌
3. 7,900亿市值 → 需要"量增"故事而不仅是"价涨"故事
4. Q3 系统性回撤（创业板-27.8%）拖累

### 3.3 估值测算
按H1年化，2026E净利约780亿元 → 7,900亿市值对应2026E PE约**10倍**。资源股10-12倍是合理区间，**这意味着当前价格几乎没有给成长溢价**。

### 3.4 与同类对比
| | 紫金矿业 | 洛阳钼业 | 中国宏桥 | 中国神华 |
|---|---|---|---|---|
| 2026H1净利增速 | +68.2% | +86.3% | +39.2% | 未获取 |

| 特征 | 铜金，业绩最强 | 铜钴，业绩更猛 | 铝，最便宜 | 煤，已兑现 |

**资金已经把"确定性分红"（煤炭）买上去了，还没买"业绩成长"（铜/铝）**——这就是方向4的全部机会。

## 六、风险提示

1. **商品价格风险**：铜金价格受宏观、美元、地缘影响，回撤剧烈
2. **增速回落风险**：Q2营收增速已从+24.8%降到+7.8%，价格依赖度上升
3. **海外运营风险**：矿山所在国的政策、税费、社区风险
4. **市值天花板**：7,900亿市值需要持续量增支撑
5. **数据口径**：Q2单季为H1−Q1推算；市值含A+H，港元按0.92折算
