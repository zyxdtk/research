# 事件驱动交易方法论

> 创建时间：2026-05-10
> 状态：框架搭建中

---

## 一、核心逻辑

市场定价的是**预期**，不是事实。关键事件改变预期 → 资产价格波动 → 产生交易机会。

**赚的是什么钱？**
- 信息差：比市场更快获取关键信息
- 认知差：对同一事件，比市场理解得更深/更准

**典型事件举例：**
- 中美谈判、关税政策
- 美联储议息会议
- 重要经济数据发布（GDP、CPI、就业）
- 地缘冲突
- 行业政策（芯片补贴、新能源政策等）

---

## 二、事件分类框架

### 按影响范围
| 类型 | 举例 | 影响标的 |
|------|------|----------|
| 宏观政策 | 美联储加息/降息、财政刺激 | 全市场、汇率、债券 |
| 地缘政治 | 中美关系、俄乌冲突、贸易谈判 | 相关产业链、避险资产 |
| 行业政策 | 芯片法案、新能源补贴、教培双减 | 特定板块 |
| 公司事件 | 财报、并购、高管变动 | 个股 |

### 按可预测性
- **确定时间点**：美联储会议、GDP发布、财报季 → 可提前布局
- **突发性**：地缘冲突、政策突变 → 需要快速反应
- **渐进性**：贸易摩擦升级、疫情扩散 → 跟踪趋势

---

## 三、事件影响判断三步法

### Step 1：定性 — 利好还是利空？
- 事件是**超预期**还是**符合预期**？（已定价的不算新闻）
- 影响的是**情绪面**还是**基本面**？
- 是**一次性事件**还是**趋势性转变**？

### Step 2：定量 — 影响多大？
- 历史上类似事件，市场反应幅度？
- 影响哪些板块/标的？
- 传导路径是什么？
  > 例：谈判 → 关税降低 → 出口企业利润增加 → 出口链股票上涨

### Step 3：择时 — 什么时候进什么时候出？
- **买预期，卖事实** — 利好落地前布局，落地后考虑兑现
- **关注预期差** — 市场觉得会崩但你判断会成，这才是真机会
- **设置止损线** — 事件驱动交易错了就要认

## 四、信息源体系

### 第一手（最快最准）
- 白宫/外交部/商务部官方声明
- 财联社/新华社电报（国内事件）
- 美联储官网 FOMC 声明

### 第二手（带分析解读）
- Bloomberg / Reuters
- 知名分析师 / Twitter 财经大V
- 华尔街见闻

### 第三手（聚合总结）
- 新闻聚合平台
- 公众号 / 知乎专栏

### 衍生信号（往往比新闻更快）
- 人民币汇率异动
- A50 期货盘后波动
- 美股中概股盘后异动
- VIX 恐慌指数

## 五、可用工具和数据源

### 📅 经济事件日历 API
| 工具 | 说明 | 链接 |
|------|------|------|
| **EODHD** | 经济事件日历 API，覆盖全球宏观事件（零售、PMI、债券拍卖等） | https://eodhd.com/financial-apis-blog/new-economic-events-calendar-api |
| **FMP (Financial Modeling Prep)** | 财报、IPO、分红、拆股等日历 API | https://site.financialmodelingprep.com/datasets/calendars |
| **OHLC.dev** | 经济日历 API，覆盖 GDP、通胀、就业、央行决议 | https://ohlc.dev/economic-calendar-api |
| **Finnworlds** | 国际宏观经济事件 API | https://finnworlds.com/economic-calendar-api/ |

### 🌍 地缘政治监控
| 工具 | 说明 | 链接 |
|------|------|------|
| **GDELT Project** | 全球最大的开放新闻数据库，覆盖全球事件，可追踪地缘政治风险 | https://gdeltproject.org |
| **World Monitor** | 基于 GDELT 的实时世界事件地图，覆盖冲突、抗议、地缘事件 | https://world-monitor.com |
| **SentinelX** | 地缘政治早期预警仪表盘，16 个实时指标（市场、冲突、OSINT、制裁） | https://mall.minddock.ai/products/sentinelx-geopolitical-early-warning-dashboard |

### 📰 新闻情绪分析
| 工具 | 说明 | 链接 |
|------|------|------|
| **VADER (NLTK)** | Python 情绪分析工具，适合英文财经新闻 | GitHub: nltk.sentiment.vader |

| **Valyu** | AI 搜索 API，包含新闻搜索和金融数据 | https://docs.valyu.ai |
