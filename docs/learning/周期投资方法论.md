# 周期投资方法论

**创建日期**：2026年10月2日
**定位**：统一报告库中散落的周期概念——存储报告的价格周期、设备报告的订单周期、零跑/美团的盈利周期、ETF报告的估值分位、底座大模型报告的五大周期仪表盘，在此给出一套通用框架。

**核心命题**：利润是周期位置的函数。终局利润导向的分析（见各报告），本质上都是在回答同一个问题——**这家公司此刻站在周期的哪个位置，未来12个月会往哪走**。

---

## 一、六种周期类型（以2026年真实案例定义）

| 周期类型 | 定义 | 2026年活案例 | 观察指标 |
|---------|------|-------------|---------|
| **1. 价格周期** | 商品/服务价格的供需波动 | 存储超级周期：1Q26 DRAM合约价环比+93~98%（"四十年一遇"短缺）→Q3收窄至+13~18% | 合约价环比斜率、现货/长协价差 |
| **2. 资本开支/订单周期** | 下游扩产→设备/材料订单波动 | 半导体设备：五大原厂交期从6个月拉到12个月，头部设备订单排至2027年，SEMI预测2026年全球设备销售1,659亿美元（+23.2%） | 订单/合同负债、CapEx指引、交期 |
| **3. 盈利周期** | 利润表的起伏（量→价→利的传导结果） | 零跑：年初目标50亿→8/24下修至30亿；美团：2025年净亏233.6亿→2026Q2单季扭亏+21.6亿 | 毛利率、单车/单位净利、指引方向 |
| **4. 库存周期** | 备货→去库→补库的循环 | 模组厂（佰维/德明利）低价库存随涨价快速变现为利润（H1净利+298%/扭亏） | 存货周转、存货减值、渠道库存 |
| **5. 渗透率/技术范式周期** | 新技术从0到1到S曲线 | AI算力五层蛋糕（芯片层30-40%价值占比）；设备国产化率35%（2024）→55%（2025）；人形机器人量产元年（H1产量4万台，全年预期10万台） | 渗透率、良率、量产节点 |
| **6. 预期/情绪周期** | 定价对未来的抢跑与杀跌 | "业绩暴涨股价腰斩"：佰维H1净利+298%但股价自高点-56%；机器人ETF估值处近1年3.19%分位 | PE/PB历史分位、资金申赎、成交拥挤度 |

> 底座大模型报告的"五大周期仪表盘"（CAPEX折旧/技术范式/ROI验证/宏观流动性/资本供给与解禁）是类型2+5+宏观的行业专用组合，见 [底座大模型_202609.md](../sectors/ai/底座大模型_202609.md) 第三章。

## 二、周期传导链（本方法论的核心）

### 2.1 商品型周期的标准传导环

```
供需缺口 → 价格上涨 → 毛利率扩张 → 利润爆发 → CapEx扩张 → 新产能投放 → 供需再平衡 → 价格回落
```

存储是教科书案例：涨价（价格周期）→ 兆易H1净利+1092%（盈利周期）→ 长鑫349亿扩产+三大原厂资本开支上调（CapEx周期）→ TrendForce预计2027年HBM供给放量后价格回落。

**应用**：在环上的位置决定操作——缺口发酵期满仓商品，CapEx密集期切换到设备/材料（它们赚的是别人的扩产钱），供给放量预告期离场商品。

### 2.2 传导时滞表："谁先受益，谁先见顶"

同一轮周期，不同环节的报表兑现时滞不同：

| 环节 | 兑现时滞 | 2026年实例 |
|------|---------|-----------|
| 模组/贸易商 | 最快（1个季度内） | 德明利H1收入169亿即刻变现库存 |
| 设计公司 | 快（1-2个季度） | 兆易Q1净利+523%，价格→利润立现 |
| 材料商 | 慢（2-4个季度，随产能爬坡） | 雅克H1仅+7.3%——涨价与扩产的拉动滞后于订单，管理层明示新增产能2027年底前才建成 |
| 设备商 | 最慢（1-2年，订单→收入） | 北方华创订单排至2027年，2026H1净利仅+5% |
| 终端制造商 | 看成本传导能力 | 零跑：量增50%但单车净利仅589元，ASP被结构恶化吞噬 |

**应用**：判断持仓在传导链的位置——如果你拿的是链条末端（设备/材料），就要忍受报表滞后，用订单而非利润验证；如果你拿的是最前端（贸易商），利润来得快去得也快，见顶信号出现时最先离场。

### 2.3 指引是周期的官方盖章

管理层指引的调整比财报更早地暴露周期位置：

- **下修 = 官方确认见顶风险**：零跑年初50亿→8/24砍到30亿（-40%），等于管理层亲手承认年初对周期的误判
- **指引反复横跳 = 周期波动剧烈**：（对照2025年新能源补贴退出期的车企指引）
- **"产能锁定至20XX年" = 管理层对周期长度的投票**：雅克称晶圆厂产能长协锁定至2028年、美光手握26份长协称"存储荒到2028"——这类表态出现时，周期通常已在中后段（所有人都开始用长期合同锁利润的时候）

## 三、周期定位仪表盘：四象限判断法

### 3.1 六大信号组合

| 信号 | 复苏期 | 主升期 | 过热期 | 衰退期 |
|------|--------|--------|--------|--------|
| 价格环比斜率 | 转正 | 陡升 | **首次收窄** | 转负 |
| 库存 | 去化尾声 | 补库 | 高位囤货 | 被动积压 |
| CapEx/订单 | 规划 | 执行 | **军备竞赛** | 砍单 |
| 管理层指引 | 上修试探 | 上修 | 维持/下修出现 | 批量下修 |
| 估值分位 | 低位 | 中位 | **高位+散户化** | 杀估值 |
| 资金流向 | 犹豫 | 净流入 | 拥挤 | 净流出（末期重新净流入） |

### 3.2 顶部特征清单（出现越多，离顶越近）

1. 现货价远超长协价（2026年HBM现货≈长协5倍——极度短缺的顶部特征而非底部特征）
2. 涨幅斜率首次显著收窄（DRAM：+93~98% → +13~18%）
3. 出现第一份下修（零跑50→30亿）
4. "业绩暴涨、股价腰斩"（佰维/江波龙/香农芯创——聪明钱先走）
5. 所有玩家都开始签长期锁定协议（供给过剩的前兆被解读成需求旺盛）
6. 散户化定价、成交拥挤、主题炒作替代基本面讨论

### 3.3 底部特征清单

1. 估值分位极端化（机器人ETF PE处近1年3.19%分位）
2. 指引出清完毕（该砍的目标都砍完了，没有更坏的消息）
3. 亏损收窄/扭亏的边际改善被市场无视（美团Q2扭亏后股价继续跌）
4. **资金与价格背离：越跌越买**（半导体设备ETF 9/29获1.53亿份净申购，价格却在创新低）
5. 行业出清加速（尾部玩家退出——汽车淘汰赛中"百万辆是活命线"的表态）

### 3.4 操作映射

| 象限 | 仓位动作 | 持仓结构 |
|------|---------|---------|
| 复苏期 | 底仓试探 | 链条最前端（弹性最大） |
| 主升期 | 满仓+浮盈加仓 | 持有斜率最陡的环节 |
| 过热期 | 只减不加 | 换仓到传导链后段（设备/材料），现金比例抬升 |
| 衰退期 | 空仓或对冲 | 留观察仓等底部特征 |

## 四、周期股估值要领

### 4.1 PE陷阱：周期顶部低PE、底部高PE

周期股的PE是反着用的：
- **利润顶部 → PE最低 → 看似便宜**（2025年煤炭/猪肉的经验）
- **利润底部/亏损 → PE畸高或失效 → 看似贵**（中微Q2净利率50%的异动、佰维扭亏后PE失真）

**对策**：周期顶部用PB/重置成本/PS交叉验证；周期底部用"正常化利润"（跨周期平均利润）算正常化PE。

### 4.2 周期位置 > 估值倍数

零跑案例：按30亿目标算PE 15倍"便宜"，按TTM算80.9倍"贵"——**两个数都对，分歧在信哪个利润**。而"信哪个利润"就是周期位置判断：30亿需要毛利率、费用率、量三个齿轮同时咬合（详见零跑_202610.md 4.7节拆解），市场按"部分咬合"定价在两者之间。

### 4.3 目标价的滞后性

机构目标价基于给出时的周期假设。指引下修后（零跑50→30亿），旧目标价（花旗113、招商139）的upside数字全部失去参考性——**下修后的第一个完整季度财报之前，目标价只是一张过期地图**。

### 4.4 不同周期类型的估值锚

| 周期类型 | 估值锚 | 反面教材 |
|---------|--------|---------|
| 价格周期（商品） | PB、重置成本、长期现金成本曲线位置 | 用PE买在价格顶部 |
| 订单周期（设备） | 在手订单/合同负债、订单同比 | 只看当期利润错过订单爆发（中微订单+50% vs PE 72"贵"） |
| 盈利周期（制造） | 正常化PE（跨周期平均） | 把单季爆发当永续 |
| 渗透率周期（成长） | PS、空间×份额×净利率终局 | 用PE否定S曲线早中期 |
| 预期周期（主题） | 分位数+资金行为，不看基本面 | 在3.19%分位讲"商业化未兑现"而不敢买 |

## 五、2026年周期实例对照（本报告库活案例）

| 标的/板块 | 所处周期 | 阶段判断 | 判断依据 |
|----------|---------|---------|---------|
| 存储（DRAM/NAND） | 价格周期 | **主升中后段** | 涨幅斜率收窄（93%→13-18%）但趋势未变；瑞银看紧缺至2028Q2；现货/长协价差极端 |
| 半导体设备 | 订单周期 | **主升期** | 订单排至2027年、盛美在手订单+88%、CapEx军备竞赛进行中；但股价先于基本面回调=预期周期开始发力 |
| 雅克（材料） | 兑现滞后段 | 主升期的报表洼地 | 订单已锁定但产能2027年底才建成——周期没错，时滞未到 |
| 零跑（汽车） | 盈利周期/行业出清 | **不确定的爬坡期** | 指引下修、H1完成7%、需H2利润5倍于2025全年；行业"百万辆是活命线"=出清期特征 |
| 美团（外卖） | 补贴战出清尾声 | 衰退后期→复苏初期 | 2025年-233.6亿巨亏出清、Q2扭亏、UE转正指引；但300亿再投入=复苏斜率打折 |
| 机器人 | 预期周期 | 主题退潮后的真空期 | 估值3.19%分位（底部特征）但催化真空（顶部特征已现——大会利好出尽） |
| AI算力（五层蛋糕） | 渗透率+CAPEX周期 | 早中段 | 国产化率55%仍在爬坡、SEMI设备市场到2028年持续增长；折旧/ROI验证周期未完成（见底座报告仪表盘） |

**使用方式**：分析任何标的时先回答三个问题——
1. 它处于哪种（哪几种）周期的什么阶段？（用3.1仪表盘打分）
2. 它在传导链的哪个位置？报表兑现时滞多久？（用2.2时滞表）
3. 当前估值锚对该周期类型是否用对了？（用第四章要领）

> ⚠️ 本方法论为分析框架记录，不构成投资建议。周期判断必然滞后于拐点，所有概率性结论都应配合止损纪律执行（见交易核心原则）。
