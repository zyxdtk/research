# 量化数据获取全攻略

作为程序员，工程与代码能力是量化交易中最核心的护城河之一。

普通人玩量化，最大的误区是想去和机构拼"高频交易（HFT）"和"毫秒级Tick数据"。对个人而言，和机构在硬件和专线上硬碰硬无异于送人头。**个人的主战场在低频（日K、小时K、分钟K）以及选股、轮动、网格、期权套利等策略。**

---

## 1. 免费/开源的"数据搬运工"（适合回测与日线级别）

如果你不需要毫秒级盯着盘面，只需要每天收盘后跑模型、选股、或者做日线级别的策略，这些开源库完全够用，几行 Python 代码就能搞定：

### AkShare (推荐)

目前国内最活跃的开源金融数据接口库。它通过爬虫技术动态解析各大财经网站（东财、新浪、财联社等）的数据。

**特点：**
- 涵盖 A 股、美股、港股、期货、宏观经济等
- **完全免费**，不需要注册 Token
- 支持获取实时快照和历史 K 线

### TuShare

老牌量化数据社区。

**特点：**
- 数据稳定
- 采用"积分制"（注册送基础积分，参与社区或付费获得高阶数据接口）
- 对 A 股基本面、财报数据的清洗做得很好

### BaoStock

专注于 A 股历史 K 线数据的开源平台。

**特点：**
- **无需注册**
- 支持标准 `pandas DataFrame` 格式
- 特别适合用来下载几年的历史日线、分钟线数据做策略回测

## 2. 券商官方 API（真正的实时流数据 + 交易一体化）

如果你想写日内策略、做网格交易、或者需要真正的**实时行情推流（WebSocket）**，直接用券商开放的 API 是最靠谱的。

### 跨境/美港股市场

#### 富途 Open API (Futu API)

程序员友好的天花板。

**如何用：**
- 只要你的富途账户里有资产，就可以在本地运行一个 `FutuOpenD` 网关程序
- 支持 Python，提供**真正的实时 Tick 数据、逐笔成交、订单簿（Order Book）推流**
- 同时支持直接代码下单

#### 老虎证券 (Tiger Open API) / 盈透证券 (IBKR API)

同样提供极度硬核的底层 API，支持全球资产的历史和实时数据流。

### 国内 A 股市场（需要向券商申请）

国内 A 股因为监管原因，个人无法直接用代码连接交易所。但现在很多券商对资产达到一定门槛（通常是 10w 或 50w 精神门槛）的个人客户开放了**量化终端**：

#### QMT (Quantitative Motion Trader) / XtQuant

目前国内券商最常用的量化客户端。

**如何用：**
- 券商会给你一个内置 Python 环境的客户端
- 其中 **XtQuant** 允许你在自己习惯的本地 IDE（如 VS Code/Cursor）中直接调用它提供的 Python 库

**能力：**
- 提供免费的 A 股实时行情、历史极细粒度数据
- 支持实盘自动化下单

## 3. 云端"全包型"量化平台（免去搭建数据库的烦恼）

如果你不想在本地写 `CRUD` 去存几百吉字节（GB）的行情数据，可以直接用国内的云端量化平台。它们把**数据、回测引擎、模拟盘**全部集成好了。

### 聚宽 (JoinQuant) / 米筐 (Ricequant)

**玩法：**
- 你直接在它们的 Web 端（Jupyter Notebook 环境）编写策略
- 它们免费提供极其精准的、处理过复权（Split/Dividend）的历史和实时行情

**进阶：**
- 它们也提供本地数据 API（如 `jqdatasdk`）
- 允许你用代码把它们服务器上的数据拉到本地来用（通常有每天免费额度）

---

## 4. 程序员的量化技术栈建议

既然能写代码，建议不要把时间浪费在造"行情接收器"的轮子上。标准的极简架构通常是：

```
[数据源: AkShare / Futu API] ──> [本地回测: Backtrader / Qlib] ──> [实盘/模拟: 券商API]
```

### 回测框架

别自己写 `for` 循环跑回测，容易产生"未来函数"（Look-ahead bias）。推荐用开源的：

- **Backtrader**（Python 老牌）
- **Qlib**（微软的 AI/机器学习导向）

### 数据存储

- 如果要存 Tick 数据：用 `ClickHouse` 或 `InfluxDB`（时序数据库）
- 如果只是分钟/日线：几个 `Parquet` 文件或 `SQLite` 足够
