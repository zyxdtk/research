# AH周期股分析框架

> 创建时间：2026-07-22
> 状态：已完成

---

## 一、整体框架

分析AH两地上市且处于周期高位的股票，需要将指标分为**短期情绪/资金类**和**长期基本面类**两大类，两者关注的重点截然不同：

| 维度 | 短期关注 | 长期关注 |
|---|---|---|
| **核心问题** | 谁在买、谁在卖、情绪如何 | 行业周期处于什么位置、盈利能否持续 |
| **主导力量** | 沽空盘、北水、技术信号 | 供需关系、产能周期、竞争格局 |
| **时间跨度** | 日/周级别 | 季/年级别 |

---

## 二、短期走势：关注情绪与资金指标

### 1. 沽空比例（卖空比例）——最核心的短期指标

H股可以做空，沽空数据是**每日可观测的空头情绪温度计**。

**使用逻辑**：
- 沽空比率**持续高于15%** → 空头情绪极度浓厚，短期可能仍有下行压力
- 沽空比率**突然飙升后回落** → 可能意味着空头回补，短期反弹信号
- 沽空金额**绝对值巨大**（如10亿+级别）→ 说明空头在"重兵押注"，需警惕基本面层面的利空

### 2. 港股通持股比例与资金流向——南向资金的立场

港股通（南向资金）是H股最重要的内地资金来源，其持仓变化反映**内地机构/大户的态度**。

**使用逻辑**：
- **持股比例持续下降** → 南向资金在撤退，短期承压
- **单日大幅减持** → 通常是事件驱动型抛售（如业绩利好兑现后的获利了结）
- **持股比例企稳或回升** → 可能意味着抛压减弱，短期底部临近

### 3. 技术指标与资金流向

- **RSI（相对强弱指标）**：判断短期超买超卖状态
- **BIAS（乖离率）**：衡量股价与均线的偏离程度
- **CCI（顺势指标）**：识别趋势强度和反转信号
- **A股融券数据**：代表A股空头态度
- **主力资金流向**：反映场内资金动向

**使用逻辑**：当多个技术指标同时出现超卖信号，且沽空比率开始回落、北水流出放缓时，短期反弹的概率增加。

## 三、长期走势：关注基本面与周期指标

### 1. 行业供需与产能扩张——周期位置的判断

这是周期股长期走势的**核心矛盾**。

**需要持续追踪的信号**：
- **主要企业的扩产公告**：金额、时间线
- **新进入者**：跨界玩家的产能规划
- **价格指数**：当前价格处于什么位置，是否出现拐点信号
- **供给释放时间表**：新产能从建设到投产通常需**1.5-2年**，这是判断景气周期长度的关键

**使用逻辑**：
- 扩产公告密集出现 → 长期供给过剩风险上升，周期顶部临近
- 如果价格开始松动而扩产仍在加速 → "戴维斯双杀"风险

### 2. 机构盈利预测与估值——业绩持续性的判断

机构预测是判断市场对长期盈利预期的**重要参考坐标**。

**使用逻辑**：
- **关注预测是否被持续上调或下调**：如果业绩超预期但机构反而下调预测 → 说明对长期持续性存疑
- **关注H股与A股的估值差距**：差距反映了两地市场对长期确定性的不同定价

### 3. 海外收入占比与全球化进展

海外业务的拓展是**打破国内周期、实现长期增长**的关键路径。需持续跟踪：
- 海外各区域的产能利用率
- 海外收入增速是否匹配甚至超越国内
- 国际贸易环境变化对海外业务的影响

## 四、综合运用：短期与长期的联动

**短期指标解决"什么时候买/卖"的问题，长期指标解决"值不值得持有"的问题。**

当短期信号和长期信号**方向一致**时（如沽空激增 + 产能扩张加速），调整的幅度和持续时间可能更长；当两者**背离**时（如短期超卖但长期逻辑未破），可能是较好的介入窗口。

### 日常需要追踪的核心数据清单

| 频率 | 指标 | 数据来源 |
|---|---|---|
| **每日** | 沽空金额、沽空比率 | 港交所披露 |
| **每日** | 港股通持股占比变动 | 港交所T+2数据 |
| **每日** | A股涨跌停、成交量 | 行情软件 |
| **每周** | 30日平均沽空比率、偏离度 | 证券之星等 |
| **不定期** | 扩产公告、价格指数 | 公司公告、CRU |
| **每季度** | 海外收入占比、毛利率 | 公司财报 |
| **每半年** | 机构盈利预测调整 | 券商研报 |

## 五、总结

1. **短期看资金情绪**：重点追踪沽空比例、北水流向、技术指标
2. **长期看周期位置**：重点追踪产能扩张、供需关系、机构盈利预测
3. **综合判断**：短期信号和长期信号的一致性是判断调整幅度的关键
4. **数据驱动**：建立日常追踪清单，避免主观臆断
